# IELTS Student Portal

A minimal Next.js (App Router) project with a starter Test Taker Portal page.

## Run locally

- Install deps: `npm install`
- Start dev server: `npm run dev`
- Open: your local `/dashboard` route through the main dev server (for example, `http://0.0.0.0:5500/dashboard`).

## Pages

- `/` – Home
- `/dashboard` – Test Taker Portal (student record data)

## Update student data

Edit the single student record in `src/lib/studentData.ts`.
